# TalentLens 🔍

TalentLens is an AI-powered resume screening system that analyzes PDF/DOCX resumes against a job description using Groq LLM. It matches candidate skills, identifies missing requirements, calculates a match score, and ranks candidates.

## Features

- PDF & DOCX resume parsing
- AI-powered skill matching
- Match percentage calculation
- Candidate ranking
- Structured hiring recommendations

## Tech Stack

- Python
- Groq API
- Pydantic
- PyPDF
- python-docx

## Run

```bash
uv sync
python miniproject.py
```
